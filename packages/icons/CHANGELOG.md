# @blip/icons

## 0.1.0

First release. 188 original icons on a 12 x 12 pixel grid: SVG files, a sprite, JS path data with the IconName type, iconSvg() and the <blip-icon> element.

- Renamed from Blip: the package is `@jaatster/blip-icons` (was `@jaatster/blip-icons`); the element is `<chu-icon>` (class `BlipIcon`, was `<pp-icon>` and `PixelIcon`), and the sprite's symbols are `chu-icon-<name>`.
- Renamed from Blip: the package is `@blip/icons` (was `@jaatster/blip-icons`); the element is `<blip-icon>` (class `BlipIcon`, was `<chu-icon>` and `BlipIcon`), and the sprite's symbols are `blip-icon-<name>`.
