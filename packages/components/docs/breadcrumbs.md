# Breadcrumbs

Where this page sits: links back up the trail, pixel chevrons between them, and the page you are on sitting in at the
end. Use them in deep structures (worlds, levels, settings sections); a flat app does not need them.

## Usage

```html
<nav class="chu-breadcrumbs" aria-label="Breadcrumb">
  <ol class="chu-breadcrumbs-list">
    <li><a class="chu-box chu-breadcrumbs-link" data-variant="ghost" href="/">Home</a></li>
    <li><a class="chu-box chu-breadcrumbs-link" data-variant="ghost" href="/worlds">Worlds</a></li>
    <li><a class="chu-box chu-breadcrumbs-link" data-variant="ghost" href="/worlds/2/3" aria-current="page">Level 2-3</a></li>
  </ol>
</nav>
```

A long trail can fold its middle into a menu:

```html
<li>
  <chu-menu class="chu-menu">
    <button class="chu-box chu-breadcrumbs-link" data-variant="ghost" aria-label="3 more pages"><svg class="chu-icon" …></svg></button>
    <div class="chu-box chu-menu-list chu-pop-in" role="menu" aria-label="More pages" popover>
      <a class="chu-box chu-menu-item" role="menuitem" href="/worlds"><span class="chu-menu-label">Worlds</span></a>
    </div>
  </chu-menu>
</li>
```

## Anatomy

1. **Trail**: `.chu-breadcrumbs-list`, an ordered list that wraps onto more lines when it must.
2. **Crumb**: `.chu-breadcrumbs-link`, a ghost box: a link in the accent text colour.
3. **Separator**: a one-pixel chevron (4 x 7) before every crumb but the first, drawn by CSS (not read out).
4. **Current page**: the last crumb, `aria-current="page"`: a soft chip, ink text, bold.

## Variants

| Attribute | Values | Use |
|---|---|---|
| `data-size` | `sm` (12 pixels high), `md` (14, default), `lg` (16) | `sm` for dense headers and dashboards, `lg` for a page's own header. |
| `<span>` inside a crumb | | A long label is cut to `--chu-breadcrumbs-max` with an ellipsis; the full text is still its name. |
| A `chu-menu` in an item | | The middle of a long trail behind a "more" button: keep the first crumb, the last two, and fold the rest. |
| An icon-only crumb | `aria-label` | A home mark instead of "Home". |

## States

| State | How | Look |
|---|---|---|
| Hover | pointer | Fills with the sunken surface and shows its outline; the label turns the scheme's text colour, which reads on that well in every scheme (the link colour falls short at Sunset). |
| Focus | keyboard | The yellow ring round the same well and label. |
| Current | `aria-current="page"` | A soft chip (accent light, ink outline), ink bold text. |

## Accessibility

| Key | Does |
|---|---|
| Tab | Through the crumbs, including the current page and the "more" button. |
| Enter | Follows a crumb; on the "more" button, opens the menu (see Menu). |

- Follows the WAI-ARIA Authoring Practices Breadcrumb pattern: a `nav` named "Breadcrumb", an ordered list, and
  `aria-current="page"` on the last link.
- The separators are generated by CSS with no text, so screen readers do not read them.
- Cut labels keep their whole text as the accessible name; add a `title` only if the cut hides something people need.
- Right to left, the chevrons turn round.
- Windows high contrast: the current page keeps a border.

## Content

- Each crumb is the page's own title, shortened if needed: "World 2: Desert Hill", not "Go to World 2".
- The last crumb is the page you are on; it matches the page's heading.

## Do and don't

- **Do** start the trail at the top of the structure, not at a random parent.
- **Don't** use breadcrumbs as the main navigation or to show history.
- **Don't** fold the trail when it fits.

## API

| Custom property | Default | |
|---|---|---|
| `--chu-breadcrumbs-max` | `calc(80 * var(--chu-pixel))` | The width at which a crumb's `<span>` is cut. |
| `--chu-r` with `--chu-shape`, `--chu-shape-inner` | 3 | Corner radius in pixels. |
